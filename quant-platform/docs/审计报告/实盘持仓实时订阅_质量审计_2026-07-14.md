## 二、HIGH（全修复）

### H1【前端·正确性·已修】applyLiveQuotes 部分行情覆盖聚合 KPI
- **位置**: static/js/live_trader.js applyLiveQuotes
- **问题**: 当 `window._lastQuotes` 不含某只持仓 code（停牌/涨跌停无 tick/网关瞬时失败/刚重渲染订阅未到），`findQuote` 对该行返回 null 跳过、不计入 totalMv，但末尾仍用**部分和**写 `lt-kpi-mv/lt-kpi-total`，最坏把后端正确的 total_asset 覆盖成 ¥0。500ms 持续覆盖、10s 后端纠正、再被打回 = 错误+闪烁。
- **修复**: 加 `matched` 计数，仅当 `matched === rows.length`（100% 覆盖）才写聚合 KPI；未全覆盖时仅更新逐行现价（优雅降级，保留上次聚合值）。逐行现价/市值/浮盈仍按行更新（未命中行保留上一次值）。
- **顺带解决**: M1（总资产前端重算 vs 后端闪烁）—— 现在只有高覆盖才写，口径冲突窗口消除。

### H2【后端·运维·已修】周末/节假日不守卫
- **位置**: server/live/broadcaster.py `_in_trading_hours`
- **问题**: 原只比 HH:MM，周六 10:00 也返回 True → 每周末 ~2000 次无效请求打 8001。与 app/live_trader/scheduler.py:107 (`weekday()>=5`) 不一致。
- **修复**: `_in_trading_hours` 加 `now.weekday() >= 5` 周末守卫。

### H3【后端·运维·已修】异常分支未限流，8001 宕机刷日志
- **位置**: server/live/broadcaster.py `_broadcast_once` 外层 except
- **问题**: 原 `except Exception` 每次都 warning，无节流。8001 挂掉时每天交易时段 ~2160 条 warning 刷屏。
- **修复**: 异常分支复用 `_fail_count` 节流（`==1 or %10==0`）；全成功时清零 + 恢复 log.info。

## 三、MEDIUM

### M1【后端·已修】单接口失败静默
- **位置**: broadcaster._broadcast_once
- **问题**: 原仅"4 接口全空"才 warning。QMT 断连时 /live/asset 503 但 positions 仍返回 → payload 非空 → fail_count 永远 0 → 无任何告警。
- **修复**: 逐接口 isinstance 检查，记录 `missing` 字段；部分失败仍推可用字段（前端有守卫），但周期 warning（`缺 [missing]`）；全空/部分失败/异常统一 `_fail_count` 计数。

### M2【集成·已修】asset 未就绪时总资产低估
- **位置**: live_trader.js applyLiveQuotes + _renderLiveAsset
- **问题**: 打开实盘 tab 时若 QMT 未连，`/live/asset` 503，`window._liveCash` 未赋值；market_quotes 到达后 applyLiveQuotes 把 total 写成 `totalMv + 0 + 0`（漏现金）。
- **修复**: `_renderLiveAsset` 成功时置 `window._liveAssetOk = true`；applyLiveQuotes 仅在 `_liveAssetOk` 时写 total/total-sub/mv-sub，否则保留后端值（KPI 显示 `—` 直到首个有效 asset 快照）。

### M3【集成·已修】applyLiveQuotes/_renderLive* 缺 try/catch
- **位置**: live_trader.js applyLiveQuotes
- **问题**: applyLiveQuotes 在 market_quotes 分支末尾 500ms 调用，无 try/catch；未来 DOM/字段演进抛错会 2 次/秒刷 console error。
- **修复**: applyLiveQuotes 整体包 `try { ... } catch(e) { console.warn('[applyLiveQuotes]', e); }`。_renderLive* 各自有空数据分支 + getElementById 守卫，snapshot 分支调用处有 `typeof === 'function'` 守卫，单独包 try 暂未加（风险低，跟进项）。

### M4【前端·已修】空仓不重置市值/总资产 KPI
- **位置**: live_trader.js _renderLivePositions 空分支
- **问题**: 清仓后空分支只清 summary/pnl，不动 lt-kpi-mv/lt-kpi-total，残留旧值最长 10s。
- **修复**: 空分支补 `lt-kpi-mv/lt-kpi-total` 清零。

### M5【前端·已修】findQuote 兜底死分支
- **位置**: live_trader.js applyLiveQuotes
- **问题**: `quotes[bareCode]` 兜底恒 undefined（_lastQuotes 键带后缀，bareCode 是裸码），死代码且误导。
- **修复**: 改为 `(typeof findQuote === 'function') ? findQuote(quotes, bareCode) : null`。

### M6【后端·取舍】非懒启动，0 客户端也轮询
- **位置**: broadcaster + main.py lifespan
- **现状**: lifespan eager 启动，即使无 ws 客户端也每 10s 拉 4 接口。
- **处理**: 在 `_broadcast_once` 开头加 `if not getattr(manager, 'active', None): return` 早退（无客户端时不发请求）。未做完整的"订阅驱动启停"（仿 MarketBroadcaster），因实盘页基本常驻，收益有限。
