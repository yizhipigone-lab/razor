## 实施阶段（修正版）

### Phase 1 — 后端骨架 (1 天)

**目标**:通知历史持久化基础设施完成，现有通知自动写入历史表

**新增文件**:
- `app/live_trader/notifications.py`（独立 `NotificationStore`，走 sync 写，不走 L1/L2 buffer）

**修改文件**:
| 文件 | 改动 |
|---|---|
| `app/live_trader/store.py` | **不改动**（保持 `LiveTraderStore` 独立，新建 `NotificationStore` 解耦） |
| `app/live_trader/notify.py` | 加 `_record_history()` + `Notifier.__init(store=None)` + 5 个方法尾部追加 |
| `app/live_trader/main.py` | lifespan 把 `NotificationStore` 注入 Notifier；加 60 秒防刷冷却 |

**SQL 表**（`notifications.py` 内自管理，不走 `store.py`）:
```sql
CREATE TABLE IF NOT EXISTS live_notifications (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    ts TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    level TEXT NOT NULL,  -- INFO / WARN / CRITICAL
    channel TEXT NOT NULL DEFAULT 'feishu',
    title TEXT NOT NULL,
    content TEXT,
    source TEXT  -- order / reconcile / kill_switch / scheduler / manual / test
);
CREATE INDEX IF NOT EXISTS idx_notifications_ts ON live_notifications(ts DESC);
CREATE INDEX IF NOT EXISTS idx_notifications_level ON live_notifications(level);
```

**关键实现**:
- `NotificationStore` 独立，不依赖 `LiveTraderStore`，**直接用 `duckdb.connect()` 单次连接 + `autocommit=True`**
- 避免 L1/L2 buffer 路径：`NotificationStore` 自己维护连接，不走 `LiveTraderStore._conn`（防止 buffer flush 前崩溃丢数据）
- `_record_history()` 在 5 个 public 方法尾部 `try/except` 追加，失败仅日志

**向后兼容**:
- `Notifier.__init` 加 `store=None`，旧调用点不传
- 5 个方法签名零变化

**验证**:
- [ ] 启动 live_trader 无 ERROR 日志
- [ ] `notifier.send("测试")` 后 `live_notifications` 表有 1 条
- [ ] 旧下单流程正常，飞书收到通知

**scheduler.py 15:30 分支**（独立于交易时段）:
```python
# _tick() 内，交易时段块之外：
if self.config.daily_summary_enabled:
    summary_time = self.config.daily_summary_time  # "15:30"
    if (current_time >= summary_time
            and current_time < _inc_minute(summary_time)
            and "daily_summary" not in self._executed_today):
        self._run_daily_summary()
        self._executed_today.add("daily_summary")
# 15:35 清理（不受 weekday 影响）：
if current_time == "15:35" and "cleanup_notif" not in self._executed_today:
    self._notif_store.cleanup_notifications(retention_days=7)
    self._executed_today.add("cleanup_notif")
```

| `static/js/main.js` | switchTab 加 `case 'alerts'`（`startPolling`）+ 所有其他 case（`stopPolling`） |

**alerts.js 关键实现**:
```javascript
let _alertsTimer = null;
function startAlertsPolling() {
    stopAlertsPolling();
    loadAlertsStatus();
    loadAlertsList('');
    _alertsTimer = setInterval(() => {
        loadAlertsStatus();
        loadAlertsList(window._currentAlertLevel || '');
    }, 15000);
}
function stopAlertsPolling() {
    if (_alertsTimer) { clearInterval(_alertsTimer); _alertsTimer = null; }
}
function filterAlerts(level) {
    window._currentAlertLevel = level;
    loadAlertsList(level);
}
```

**switchTab 改造**:
```javascript
case 'alerts':
    startAlertsPolling();
    break;
default:
    stopAlertsPolling();
    break;
```

**加载顺序保证**:
- `alerts.js` 在 `live_trader.js` **之后**加载
- `main.js` 的 `switchTab` 里用 `typeof startAlertsPolling !== 'undefined'` 守卫
