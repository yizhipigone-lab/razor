## 风险与边界

| 风险 | 缓解 |
|---|---|
| TestClient 写测试发现大量 schema 错位 | 预期会有 5-15 个 fail 要修,**好事** |
| Windows CI runner 慢 | 接受,缓存 pip 加速 |
| **Python 3.13 兼容性雷**（match/case、ExceptionGroup、PEP 695） | 执行前 grep 一遍,有问题降 Python 3.12 |
| **DuckDB 在 Windows CI 并发锁问题**（CLAUDE.md 明确警告） | 用 `pytest -n 0` 单进程跑,不加 pytest-xdist |
| **GitHub Actions 免费额度 2000 分钟/月** | windows-latest 启动 60-90s,加 `concurrency: group: ${{ github.workflow }}-${{ github.ref }}` 防重复跑 |
| coverage 门槛一次升 60 会让现有代码暴露 | 先 50 → 写新测试补到 60 → 再升 |
| 测试依赖 QMT/Redis mock 复杂 | 复用现有 mock fixture（248 处 mock 经验）,新建 `live_trader_client` fixture |
