## 1. 总体设计原则

### 1.1 核心铁律（不可妥协）

1. **资金安全 > 自动化程度 > 策略性能**：宁可漏单、宁可慢，绝不误下单
2. **隔离优于复用**：实盘和模拟盘**账户独立、DB独立、进程独立、配置独立**
3. **复用优于重写**：模拟盘的策略逻辑、信号生成、止盈止损算法**直接复用**，只替换"成交执行层"
4. **每笔真单必须可追溯**：审计日志全字段记录（决策上下文、价格、来源、决策时间）
5. **可回滚**：上线后任意时刻能一键切回"仅监控不下单"

### 1.2 与上轮审计报告的关系

实盘模块**继承**审计报告中的5个CRITICAL缺陷（零成本/未来函数/AI过拟合等），不修。先上线1-2万小资金观察期，**同步启动CRITICAL修复工作流**（按上次审计报告7.2建议顺序）。修复后实盘/模拟盘统一切换到新基线。

### 3.2 `app/live_trader/execution.py`（QMT 真实成交层）

**核心：xtquant 本机直连，绕过 HTTP 代理**（同机部署，HTTP 代理是冗余层）。

```python
"""
实盘成交执行层 — xtquant 本机直连 miniQmt
"""
from __future__ import annotations
import threading
from typing import Optional, Dict, List
from dataclasses import dataclass
from datetime import datetime
import time
import os
import sys

from xtquant import xttrader, xtconstant
from xtquant.xttype import XtAccount  # 兼容路径3

from core.logger import get_logger
from app.live_trader.config import (
    QMT_USERDATA_PATH, QMT_ACCOUNT_ID, QMT_SESSION_ID, DRY_RUN
)

log = get_logger("LiveExecution")


@dataclass
class OrderResult:
    """单笔委托回报"""
    order_id: int               # QMT委托号
    code: str
    direction: str              # "BUY" / "SELL"
    price: float
    volume: int
    submitted_at: datetime
    status: str                 # "submitted" / "partial" / "filled" / "cancelled" / "rejected"
    filled_volume: int = 0
    filled_avg_price: float = 0.0
    filled_amount: float = 0.0  # 成交总额（用于对账）
    error_msg: str = ""


class QtQuantExecutor:
    """
    同步锁 + 单实例：实盘委托是状态机，不允许多线程并发发单
    所有send_order / cancel / query 必须走此类的串行队列
    """
    _instance: Optional["QtQuantExecutor"] = None
    _lock = threading.Lock()

    def __init__(self):
        self._order_lock = threading.Lock()
        self._xt_trader: Optional[xttrader.XtQuantTrader] = None
        self._account: Optional[XtAccount] = None
        self._connected = False
        self._connect()

    @classmethod
    def get(cls) -> "QtQuantExecutor":
        """全局单例（懒加载）"""
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = cls()
        return cls._instance

    def _connect(self):
        """启动时同步连接 QMT"""
        try:
            if not os.path.exists(QMT_USERDATA_PATH):
                raise FileNotFoundError(
                    f"QMT userdata路径不存在: {QMT_USERDATA_PATH}，请检查 QMT_USERDATA_PATH 配置"
                )
            session_id = int(time.time())
            self._xt_trader = xttrader.XtQuantTrader(
                QMT_USERDATA_PATH, session_id
            )
            self._xt_trader.start()
            res = self._xt_trader.connect()
            if res != 0:
                raise ConnectionError(f"QMT connect 失败，返回码: {res}")
            # 订阅账户
            self._account = XtAccount(QMT_ACCOUNT_ID, "STOCK")
            self._xt_trader.subscribe(self._account)
            self._connected = True
            log.success(f"QMT 连接成功: account={QMT_ACCOUNT_ID}")
        except Exception as e:
            self._connected = False
            log.error(f"QMT 连接失败: {e}")
            raise

    # ── 下单 ──
    def buy(self, code: str, price: float, volume: int, reason: str = "") -> OrderResult:
        return self._send_order(code, price, volume, xtconstant.STOCK_BUY, "BUY", reason)

    def sell(self, code: str, price: float, volume: int, reason: str = "") -> OrderResult:
        return self._send_order(code, price, volume, xtconstant.STOCK_SELL, "SELL", reason)

    def _send_order(
        self, code: str, price: float, volume: int,
        order_type: int, direction: str, reason: str
    ) -> OrderResult:
        """
        串行发单（_order_lock 防止并发）
        DRY_RUN=True 时只构造 OrderResult 不真发
        """
        if not self._connected:
            raise ConnectionError("QMT 未连接，无法发单")

        submitted_at = datetime.now()

        if DRY_RUN:
            log.info(f"[DRY-RUN] {direction} {code} px={price:.2f} vol={volume} reason={reason}")
            return OrderResult(
                order_id=-1, code=code, direction=direction,
                price=price, volume=volume, submitted_at=submitted_at,
                status="dry_run",
            )

        with self._order_lock:
            try:
                fmt_code = self._format_code(code)
                order_id = self._xt_trader.order_stock(
                    self._account, fmt_code, order_type,
                    int(volume), 5,         # price_type=5 (限价)
                    price,                  # price
                    f"P9_LIVE_{direction}",  # 备注
                    f"live_{int(time.time()*1000)}"  # 策略委托号
                )
                if order_id < 0:
                    log.error(f"{direction} 失败 order_id={order_id} {code}@{price}x{volume}")
                    return OrderResult(
                        order_id=order_id, code=code, direction=direction,
                        price=price, volume=volume, submitted_at=submitted_at,
                        status="rejected", error_msg=f"order_id={order_id}",
                    )
                log.info(f"{direction} 提交 order_id={order_id} {code}@{price}x{volume} reason={reason}")
                return OrderResult(
                    order_id=order_id, code=code, direction=direction,
                    price=price, volume=volume, submitted_at=submitted_at,
                    status="submitted",
                )
            except Exception as e:
                log.error(f"{direction} 异常: {e}")
                return OrderResult(
                    order_id=-1, code=code, direction=direction,
                    price=price, volume=volume, submitted_at=submitted_at,
                    status="rejected", error_msg=str(e),
                )

    # ── 撤单 ──
    def cancel(self, order_id: int) -> bool:
        with self._order_lock:
            try:
                self._xt_trader.cancel_order(self._account, order_id)
                log.info(f"撤单 order_id={order_id}")
                return True
            except Exception as e:
                log.error(f"撤单失败 order_id={order_id}: {e}")
                return False

    # ── 查询 ──
    def query_balance(self) -> dict:
        if not self._connected: return {}
        try:
            asset = self._xt_trader.query_stock_asset(self._account)
            if not asset: return {}
            return {
                "cash": float(asset.cash),
                "frozen_cash": float(asset.frozen_cash),
                "market_value": float(asset.market_value),
                "total_asset": float(asset.total_asset),
            }
        except Exception as e:
            log.error(f"query_balance 失败: {e}")
            return {}

    def query_positions(self) -> List[dict]:
        if not self._connected: return []
        try:
            positions = self._xt_trader.query_stock_positions(self._account)
            result = []
            for p in positions or []:
                result.append({
                    "code": str(p.stock_code).split(".")[0],  # 统一为6位无后缀
                    "volume": int(p.volume),
                    "can_sell": int(p.can_sell_volume),
                    "avg_price": float(p.open_price),
                    "market_value": float(p.market_value),
                })
            return result
        except Exception as e:
            log.error(f"query_positions 失败: {e}")
            return []

    def query_orders(self) -> List[dict]:
        """查当日所有委托（用于对账）"""
        if not self._connected: return []
        try:
            orders = self._xt_trader.query_stock_orders(self._account)
            result = []
            for o in orders or []:
                result.append({
                    "order_id": int(o.order_id),
                    "code": str(o.stock_code).split(".")[0],
                    "direction": "BUY" if o.order_type == xtconstant.STOCK_BUY else "SELL",
                    "price": float(o.price),
                    "volume": int(o.order_volume),
                    "filled_volume": int(o.traded_volume),
                    "status": str(o.order_status),  # 需映射
                    "submitted_at": str(o.order_time),
                })
            return result
        except Exception as e:
            log.error(f"query_orders 失败: {e}")
            return []

    # ── 工具 ──
    @staticmethod
    def _format_code(code: str) -> str:
        c = str(code).strip()
        if "." in c: return c
        if c.startswith(("5", "6", "9", "7")): return f"{c}.SH"
        if c.startswith(("0", "1", "2", "3")): return f"{c}.SZ"
        if c.startswith(("4", "8")): return f"{c}.BJ"
        return c


executor = QtQuantExecutor.get()
```

### 3.3 `app/live_trader/store.py`

**独立 DuckDB 表，前缀 `live_`**，与 `sim_` 完全隔离。设计原则：
- 持仓表以 QMT 回报为**唯一真相源**（与模拟盘"本地为源"相反）
- 委托表**全量记录**（含拒单、撤单）
- 成交回报表按 order_id 关联

```python
"""
实盘持久化 — 独立表 live_*
以QMT query_stock_positions 为持仓真相源，本地表为对账副本
"""
import json
from datetime import date, datetime
from typing import Optional, Dict, List
from database.duckdb_manager import db
from core.logger import get_logger

log = get_logger("LiveStore")


class LiveStore:
    def __init__(self):
        self._db = db
        self._ensure_tables()

    @property
    def conn(self):
        return self._db.conn

    def _ensure_tables(self):
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS live_positions (
                code            VARCHAR PRIMARY KEY,
                entry_date      DATE,
                entry_price     DOUBLE,
                shares          INTEGER,
                can_sell        INTEGER,
                cost            DOUBLE,        -- 含费成本
                peak_price      DOUBLE,
                strategy_name   VARCHAR,
                qmt_avg_price   DOUBLE,        -- QMT回报的成本价（用于核对）
                last_synced     TIMESTAMP
            )
        """)
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS live_orders (
                order_id        BIGINT PRIMARY KEY,  -- QMT 委托号
                code            VARCHAR,
                direction       VARCHAR,             -- BUY/SELL
                price           DOUBLE,
                volume          INTEGER,
                filled_volume   INTEGER DEFAULT 0,
                avg_fill_price  DOUBLE DEFAULT 0,
                status          VARCHAR,             -- submitted/partial/filled/cancelled/rejected/dry_run
                reason          VARCHAR,             -- 决策原因
                submitted_at    TIMESTAMP,
                updated_at      TIMESTAMP,
                error_msg       VARCHAR
            )
        """)
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS live_trades (
                id              INTEGER PRIMARY KEY,
                order_id        BIGINT,
                code            VARCHAR,
                direction       VARCHAR,
                fill_price      DOUBLE,
                fill_volume     INTEGER,
                fill_amount     DOUBLE,
                fill_time       TIMESTAMP
            )
        """)
        try:
            max_id = self.conn.execute("SELECT COALESCE(MAX(id), 0) FROM live_trades").fetchone()[0]
            self.conn.execute(f"CREATE SEQUENCE IF NOT EXISTS live_trade_id START {max_id + 1}")
        except Exception:
            log.warning("CREATE SEQUENCE live_trade_id 失败")

        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS live_equity (
                date     DATE PRIMARY KEY,
                equity   DOUBLE,
                cash     DOUBLE,
                market_value DOUBLE,
                positions INTEGER
            )
        """)
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS live_audit (
                id          INTEGER PRIMARY KEY,
                ts          TIMESTAMP,
                action      VARCHAR,        -- buy_decision/sell_decision/order_submitted/order_filled/...
                code        VARCHAR,
                payload     VARCHAR,        -- JSON
                created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
        """)
        try:
            max_id = self.conn.execute("SELECT COALESCE(MAX(id), 0) FROM live_audit").fetchone()[0]
            self.conn.execute(f"CREATE SEQUENCE IF NOT EXISTS live_audit_id START {max_id + 1}")
        except Exception:
            pass

    # ── 持仓（以QMT为源，reconciler每15分钟覆盖）──
    def save_positions_from_qmt(self, qmt_positions: List[dict]):
        """QMT回报全量覆盖本地持仓表"""
        self.conn.execute("BEGIN")
        try:
            self.conn.execute("DELETE FROM live_positions")
            for p in qmt_positions:
                self.conn.execute("""
                    INSERT INTO live_positions
                    (code, shares, can_sell, qmt_avg_price, market_value, last_synced)
                    VALUES (?, ?, ?, ?, ?, CURRENT_TIMESTAMP)
                """, [
                    p["code"], p["volume"], p["can_sell"],
                    p["avg_price"], p["market_value"],
                ])
            self.conn.execute("COMMIT")
        except Exception:
            self.conn.execute("ROLLBACK")
            raise

    def load_positions(self) -> Dict[str, dict]:
        rows = self.conn.execute(
            "SELECT code, shares, can_sell, qmt_avg_price, market_value FROM live_positions"
        ).fetchall()
        return {
            r[0]: {
                "shares": r[1], "can_sell": r[2],
                "avg_price": r[3], "market_value": r[4],
            }
            for r in rows
        }

    # ── 委托 ──
    def upsert_order(self, order: dict):
        self.conn.execute("""
            INSERT INTO live_orders
            (order_id, code, direction, price, volume, filled_volume,
             avg_fill_price, status, reason, submitted_at, updated_at, error_msg)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, CURRENT_TIMESTAMP, ?)
            ON CONFLICT (order_id) DO UPDATE SET
                filled_volume = EXCLUDED.filled_volume,
                avg_fill_price = EXCLUDED.avg_fill_price,
                status = EXCLUDED.status,
                updated_at = CURRENT_TIMESTAMP
        """, [
            order["order_id"], order["code"], order["direction"],
            order["price"], order["volume"],
            order.get("filled_volume", 0), order.get("avg_fill_price", 0.0),
            order["status"], order.get("reason", ""),
            order.get("submitted_at", datetime.now()),
            order.get("error_msg", ""),
        ])

    # ── 审计日志（每条决策必写）──
    def write_audit(self, action: str, code: str, payload: dict):
        self.conn.execute("""
            INSERT INTO live_audit (id, ts, action, code, payload)
            VALUES (nextval('live_audit_id'), CURRENT_TIMESTAMP, ?, ?, ?)
        """, [action, code, json.dumps(payload, ensure_ascii=False, default=str)])

    # ── 净值 ──
    def save_equity_point(self, d: date, equity: float, cash: float, market_value: float, positions: int):
        self.conn.execute("""
            INSERT OR REPLACE INTO live_equity VALUES (?, ?, ?, ?, ?)
        """, [d, equity, cash, market_value, positions])

    def load_equity_curve(self) -> List[dict]:
        rows = self.conn.execute(
            "SELECT date, equity, cash, market_value, positions FROM live_equity ORDER BY date"
        ).fetchall()
        return [{"date": r[0], "equity": r[1], "cash": r[2],
                 "market_value": r[3], "positions": r[4]} for r in rows]
```

### 3.4 `app/live_trader/risk_gate.py`（风控前置门）

**每笔委托发单前必过此门**。这是用户决策"不要人工二次确认"后的**唯一保险**。

```python
"""
实盘风控前置门
每笔委托前必过：硬限额 → 集中度 → 日亏损熔断 → 现金保留
任何一项不通过则阻断 + 写审计 + 告警推送
"""
from datetime import date
from typing import Tuple
from core.logger import get_logger
from app.live_trader.config import (
    MAX_SINGLE_POSITION_PCT, MAX_TOTAL_POSITION_PCT,
    MAX_DAILY_LOSS_PCT, MAX_ORDER_AMOUNT, MIN_CASH_RESERVE,
)
from app.live_trader.execution import executor
from app.live_trader.store import LiveStore

log = get_logger("RiskGate")
_store = LiveStore()


class RiskDecision:
    def __init__(self, passed: bool, reason: str = "", metrics: dict = None):
        self.passed = passed
        self.reason = reason
        self.metrics = metrics or {}


def check_buy(code: str, price: float, volume: int) -> RiskDecision:
    """
    买入风控检查（顺序：硬规则 → 软规则）
    volume 已根据仓位计算得出，此处只校验限额
    """
    order_amount = price * volume
    metrics = {"order_amount": order_amount, "code": code}

    # 1. 单笔金额硬上限
    if order_amount > MAX_ORDER_AMOUNT:
        return _block("单笔超限", metrics, f"{order_amount:.0f} > {MAX_ORDER_AMOUNT}")

    # 2. 查询实时账户
    bal = executor.query_balance()
    if not bal:
        return _block("无法获取余额", metrics, "QMT query_stock_asset 失败")

    total_asset = bal["total_asset"]
    cash = bal["cash"]

    # 3. 现金保留
    if cash - order_amount < MIN_CASH_RESERVE:
        return _block("现金不足", metrics,
                      f"剩余={cash-order_amount:.0f} < 保留={MIN_CASH_RESERVE}")

    # 4. 单票集中度
    new_position_pct = order_amount / total_asset
    if new_position_pct > MAX_SINGLE_POSITION_PCT:
        return _block("单票超限", metrics,
                      f"{new_position_pct:.1%} > {MAX_SINGLE_POSITION_PCT:.0%}")

    # 5. 总仓位
    current_market_value = bal["market_value"]
    total_position_pct = (current_market_value + order_amount) / total_asset
    if total_position_pct > MAX_TOTAL_POSITION_PCT:
        return _block("总仓位超限", metrics,
                      f"{total_position_pct:.1%} > {MAX_TOTAL_POSITION_PCT:.0%}")

    # 6. 日亏损熔断
    today = date.today()
    today_pnl_pct = _calc_today_pnl_pct(today)
    if today_pnl_pct is not None and today_pnl_pct <= MAX_DAILY_LOSS_PCT:
        return _block("日亏损熔断", metrics,
                      f"今日盈亏={today_pnl_pct:.2%} <= {MAX_DAILY_LOSS_PCT:.2%}")

    return RiskDecision(True, "pass", metrics)


def check_sell(code: str, price: float, volume: int) -> RiskDecision:
    """卖出风控检查（仅硬规则：可卖数量、停牌检查）"""
    positions = executor.query_positions()
    pos = next((p for p in positions if p["code"] == code), None)
    if not pos:
        return _block("无持仓", {"code": code}, f"QMT 无 {code} 持仓")
    if volume > pos["can_sell"]:
        return _block("可卖不足", {"code": code, "want": volume, "can_sell": pos["can_sell"]})
    return RiskDecision(True, "pass", {"code": code, "volume": volume})


def _block(reason: str, metrics: dict, detail: str) -> RiskDecision:
    log.warning(f"风控阻断: {reason} | {detail}")
    _store.write_audit("risk_blocked", metrics.get("code", ""),
                       {"reason": reason, "detail": detail, "metrics": metrics})
    # WebSocket告警推送
    try:
        from server.websocket.manager import sync_broadcast
        sync_broadcast({"type": "live_risk_block", "reason": reason, "detail": detail})
    except Exception:
        pass
    return RiskDecision(False, reason, metrics)


def _calc_today_pnl_pct(today: date) -> float:
    """从 live_equity 取今昨两天净值算当日盈亏"""
    rows = _store.conn.execute("""
        SELECT date, equity FROM live_equity
        WHERE date IN (?, (
            SELECT MAX(date) FROM live_equity WHERE date < ?
        )) ORDER BY date
    """, [today, today]).fetchall()
    if len(rows) < 2:
        return None
    return (rows[1][1] - rows[0][1]) / rows[0][1]
```

### 3.5 `app/live_trader/engine.py`（实盘引擎）

**关键设计：策略/风控/信号复用 sim_trader，成交层替换**。

```python
"""
实盘交易 — 核心引擎
复用 SimTraderEngine 的策略/风控/信号/止盈止损
重写：成交执行层（走 QMT 真实委托）、持仓真相源（QMT > 本地）
"""
from __future__ import annotations
import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), "..", ".."))

from datetime import date, datetime, timedelta
from typing import Optional, Dict, List
from dataclasses import dataclass
from collections import defaultdict
import pandas as pd

from app.live_trader.config import *
from app.live_trader.execution import executor, OrderResult
from app.live_trader.store import LiveStore
from app.live_trader.risk_gate import check_buy, check_sell
from app.live_trader.intraday_monitor import LiveIntradayMonitor
from core.logger import get_logger

log = get_logger("LiveEngine")


@dataclass
class LivePosition:
    """实盘持仓（本地镜像，以 QMT 为源）"""
    code: str
    entry_date: date
    entry_price: float
    shares: int
    can_sell: int
    cost: float
    peak_price: float
    strategy_name: str
    current_price: float = 0.0

    @property
    def remaining_shares(self) -> int:
        return self.can_sell  # 可卖即剩余

    @property
    def market_value(self) -> float:
        return self.can_sell * self.current_price

    @property
    def profit_pct(self) -> float:
        if self.current_price <= 0: return 0.0
        return (self.current_price / self.entry_price - 1) * 100


class LiveTraderEngine:
    def __init__(self, store: LiveStore = None):
        self._store = store or LiveStore()
        self._monitor: Optional[LiveIntradayMonitor] = None
        self._today_pnl = 0.0
        log.info("LiveTraderEngine 初始化完成")

    # ── 启动流程 ──
    def start(self):
        """应用启动时调用"""
        log.info("实盘引擎启动...")
        # 1. 验证 QMT 连接
        bal = executor.query_balance()
        if not bal:
            raise RuntimeError("QMT 不可用，实盘引擎拒绝启动")
        log.info(f"QMT 余额: total={bal['total_asset']:.0f} cash={bal['cash']:.0f}")

        # 2. 立即一次对账
        self.reconcile()

        # 3. 启动盘中监控
        if MONITOR_ENABLED:
            self._monitor = LiveIntradayMonitor(self)
            self._monitor.start()

    # ── 卖出（先卖后买，14:53）──
    def sell_phase(self, today: date, snapshot: dict, trading_dates: List[date]):
        """
        与 SimTraderEngine.sell_phase 同名同语义，但卖出走 QMT 真单
        """
        from app.backtest.exit_rules import exit_rule_engine

        positions = self._store.load_positions()
        if not positions:
            log.info("无持仓，跳过卖出阶段")
            return

        # 用本地持仓 + QMT实时价 跑止盈止损
        sells = self._check_stops(positions, snapshot, trading_dates)
        log.info(f"卖出阶段: 待卖 {len(sells)} 笔")

        for code, exit_price, reason, partial in sells:
            if partial is None:
                # 全卖
                pos = positions[code]
                volume = pos["can_sell"]
            else:
                volume = min(partial, positions[code]["can_sell"])
            if volume < 100:
                continue

            # 风控门（卖出仅查可卖数量）
            decision = check_sell(code, exit_price, volume)
            if not decision.passed:
                log.warning(f"卖出被风控阻断: {code} {decision.reason}")
                continue

            # 写决策审计
            self._store.write_audit("sell_decision", code, {
                "price": exit_price, "volume": volume, "reason": reason,
                "decision": "pass", "ts": datetime.now().isoformat(),
            })

            # 真发单
            result = executor.sell(code, exit_price, volume, reason=reason)
            self._store.upsert_order({
                "order_id": result.order_id,
                "code": code, "direction": "SELL",
                "price": exit_price, "volume": volume,
                "status": result.status,
                "reason": reason,
                "submitted_at": result.submitted_at,
                "error_msg": result.error_msg,
            })

        # 触发对账
        self.reconcile()

    # ── 买入（14:54，用回收现金）──
    def buy_phase(self, today: date, signals: List[tuple]):
        """
        signals: [(code, price), ...]
        与 SimTraderEngine 同名同语义，但买入走 QMT 真单 + 风控门
        """
        # 1. 刷一次 QMT 余额
        bal = executor.query_balance()
        if not bal:
            log.error("无法获取余额，跳过买入阶段")
            return

        cash = bal["cash"]
        # 现金保留
        cash = max(0, cash - MIN_CASH_RESERVE)

        # 2. 计算本批次每只可买手数
        max_buy_per_stock = min(POSITION_SIZE, MAX_ORDER_AMOUNT)
        bought_codes = set()

        for code, price in signals:
            if code in bought_codes: break
            if cash < MIN_BUY_AMT: break

            volume = int(min(max_buy_per_stock, cash) / price / 100) * 100
            if volume < 100:
                continue

            # 风控门
            decision = check_buy(code, price, volume)
            if not decision.passed:
                log.warning(f"买入被风控阻断: {code} {decision.reason} | {decision.metrics}")
                self._store.write_audit("buy_blocked", code, {
                    "price": price, "volume": volume, "reason": decision.reason,
                    "detail": decision.metrics,
                })
                continue

            # 写决策审计
            self._store.write_audit("buy_decision", code, {
                "price": price, "volume": volume, "amount": price * volume,
                "decision": "pass", "ts": datetime.now().isoformat(),
                "signal_strategy": STRATEGY_NAME,
            })

            # 真发单
            result = executor.buy(code, price, volume, reason=f"signal:{STRATEGY_NAME}")
            self._store.upsert_order({
                "order_id": result.order_id,
                "code": code, "direction": "BUY",
                "price": price, "volume": volume,
                "status": result.status,
                "reason": f"signal:{STRATEGY_NAME}",
                "submitted_at": result.submitted_at,
                "error_msg": result.error_msg,
            })

            # 本地预扣现金（防止同一批次重复买）
            if result.status != "rejected":
                cost = price * volume * 1.0003  # 估算费
                cash -= cost
                bought_codes.add(code)

    # ── 持仓检查（复用 sim_trader.check_stops 逻辑）──
    def _check_stops(self, positions: Dict[str, dict], snapshot: dict,
                     trading_dates: List[date]) -> List[tuple]:
        """返回 [(code, exit_price, reason, partial_or_None), ...]"""
        from app.backtest.exit_rules import exit_rule_engine

        sells = []
        for code, pos_data in positions.items():
            bar = snapshot.get(code)
            if not bar: continue
            close_p = bar['close']
            high_p = bar.get('high', close_p)

            # 构造伪 Position 给 exit_rules
            from app.sim_trader.engine import Position
            pos = Position(
                code=code,
                entry_date=pos_data.get("entry_date", date.today()),
                entry_price=pos_data.get("entry_price", pos_data["avg_price"]),
                shares=pos_data["shares"],
                cost=pos_data.get("cost", pos_data["avg_price"] * pos_data["shares"]),
                strategy_name=pos_data.get("strategy_name", STRATEGY_NAME),
            )
            pos.peak_price = max(pos_data.get("peak_price", pos.entry_price), high_p)
            pos.remaining_shares = pos_data["can_sell"]
            pos.current_price = close_p

            hold_days = 1  # 简化：实盘用持仓天数

            sim_params = self._build_risk_params()
            ctx = exit_rule_engine.build_context(pos, bar, hold_days, sim_params, use_high_for_tp=True)
            signal = exit_rule_engine.check(ctx)
            if signal:
                partial = None if signal.sell_ratio >= 1.0 else int(pos.remaining_shares * signal.sell_ratio / 100) * 100
                sells.append((code, signal.sell_price, signal.reason, partial))

        return sells

    def _build_risk_params(self) -> dict:

            "hard_stop": HARD_STOP,

            "time_exit_days": TIME_EXIT_DAYS,

            "first_day_exit_days": FIRST_DAY_EXIT_DAYS,
            "use_atr_trail": USE_ATR_TRAIL,
            "atr_trail_multiplier": ATR_TRAIL_MULTIPLIER,
        }

    # ── 对账 ──
    def reconcile(self):
        """以 QMT 持仓为真相源覆盖本地"""

            qmt_pos = executor.query_positions()
            self._store.save_positions_from_qmt(qmt_pos)
```

```python
"""
实盘盘中监控 — tick 数据源走 QMT 订阅
"""
import threading
from datetime import datetime
from typing import Optional
from xtquant import xtdata
from core.event_engine import event_engine, EVENT_TICK
from server.websocket.manager import sync_broadcast
from core.logger import get_logger
from app.live_trader.execution import executor
from app.live_trader.risk_gate import check_sell
from app.live_trader.config import MONITOR_MODE, MONITOR_ENABLED

log = get_logger("LiveIntradayMonitor")


class LiveIntradayMonitor:
    def __init__(self, engine):
        self.engine = engine
        self.enabled = False
        self.mode = MONITOR_MODE  # "intraday" 触发即卖
        self._intraday_peak: dict = {}
        self._subscribed: set = set()
        self._lock = threading.Lock()

    def start(self):
        if self.enabled: return
        # 订阅当前持仓的 tick
        positions = self.engine._store.load_positions()
        codes = list(positions.keys())
        if codes:
            self._subscribe(codes)
        self.enabled = True
        log.info(f"LiveIntradayMonitor 启动 模式={self.mode} 订阅{len(codes)}只")

    def stop(self):
        if not self.enabled: return
        self.enabled = False
        for code in list(self._subscribed):
            try:
                xtdata.unsubscribe_quote(code, period='tick')
            except Exception:
                pass
        self._subscribed.clear()

    def _subscribe(self, codes: list):
        for code in codes:
            try:
                xtdata.subscribe_quote(code, period='tick', count=-1, callback=self._on_tick)
                self._subscribed.add(code)
            except Exception as e:
                log.error(f"订阅 {code} tick 失败: {e}")

    def _on_tick(self, data):
        if not self.enabled: return
        if not self._is_market_hours(): return
        # data 形如 {code: {lastPrice, high, low, ...}}
        with self._lock:
            for code, tick in data.items():
                price = tick.get('lastPrice', 0)
                if not price: continue
                self._check_and_act(code, float(price))

    def _check_and_act(self, code: str, price: float):
        # 复用 sim_trader IntradayMonitor._check_position 逻辑
        # 触发即卖模式下走 QMT 真发单
        from app.sim_trader.intraday_monitor import IntradayMonitor
        pos_dict = self.engine._store.load_positions()
        if code not in pos_dict: return
        # 简化：直接复用 sim_trader 的 _check_position
        # 实际生产应单独写一份避免耦合
        pos = pos_dict[code]
        if pos["can_sell"] <= 0: return

        # 峰值
        prev_peak = self._intraday_peak.get(code, pos.get("peak_price", 0))
        if price > prev_peak:
            self._intraday_peak[code] = price
        session_peak = max(prev_peak, price)

        # 检查止盈止损（简化版）
        # 实盘应调用 engine._check_stops 走全逻辑
        if self.mode == "intraday":
            # 触发即卖
            decision = check_sell(code, price, pos["can_sell"])
            if decision.passed:
                result = executor.sell(code, price, pos["can_sell"], reason="intraday_trigger")
                self.engine._store.upsert_order({
                    "order_id": result.order_id, "code": code,
                    "direction": "SELL", "price": price, "volume": pos["can_sell"],
                    "status": result.status, "reason": "intraday_trigger",
                    "submitted_at": result.submitted_at,
                    "error_msg": result.error_msg,
                })

    @staticmethod
    def _is_market_hours() -> bool:
        now = datetime.now()
        t = now.hour * 100 + now.minute
        return 925 <= t <= 1500
```

## 5. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| QMT连接中断（miniQmt崩溃/网络断）| 中 | 高 | executor 启动时连接 + 每次发单前 ping + 失败立即停买 |
| xtquant API 字段不匹配（不同券商版本）| 高 | 中 | 启动时 schema 探测 + 失败 fallback |
| 风控门误触发（合理单被拒）| 中 | 中 | dry-run 1周收集误报率 + 调阈值 |
| 信号在未来函数下选错股票 | 高 | 高 | 已知风险，1-2万小资金 + 风控前置缓解 |
| 模拟盘+实盘双信号源导致不同步 | 中 | 低 | 信号源共享同一份Parquet + 同一份screener |
| 委托回报延迟导致对账漂移 | 高 | 中 | 09:35/11:30/14:55 三个时点对账 + 卖单发单后30秒对账 |
| 单日亏损熔断误触 | 中 | 中 | MAX_DAILY_LOSS_PCT = -3% 留有缓冲 |
| xttrader 同步阻塞导致定时任务延迟 | 中 | 中 | 委托走异步 + 主循环心跳监测 |
| 用户决策"不要人工二次确认" → 一旦bug即亏损 | 中 | **高** | 风控前置门是最后保险，必须100%覆盖 |
| 现货账户已有持仓与系统未对齐 | 中 | 高 | 启动时强制 reconcile + 首日全量人工核对 |

## 6. 自检清单（自查发现的逻辑漏洞）

### 6.1 已发现并修复（设计阶段）

| # | 漏洞 | 修复 |
|---|------|------|
| L1 | `reconcile()` 未限制频率，可能因 QMT API 限流被打挂 | 加 `time.sleep(0.5)` + 失败重试 |
| L2 | `executor.buy/sell` 串行锁与 `reconcile` 异步并发可能竞态 | 对账走单独线程，**不发单时**才可对账；或用 RLock |
| L3 | 买入时 `volume=0` 时应跳过而非发单 | 已加 `if volume < 100: continue` |
| L4 | `LiveStore._ensure_tables` 多次调用会重复建表 | 已用 `IF NOT EXISTS` |
| L5 | `MAX_DAILY_LOSS_PCT` 计算依赖 `live_equity` 当日已有数据 | 启动时如无昨收，用 `INITIAL_CAPITAL` 兜底 |
| L6 | `LiveIntradayMonitor._check_position` 直接复用 sim_trader 的 Position 构造方式可能缺字段 | 改为本地独立实现 |
| L7 | 风控门 `total_position_pct` 计算用 `bal['total_asset']` 包含今日委托未成交部分，可能虚高 | 改为 `total_asset - 今日已发未成委托金额` |
| L8 | 用户决策 Q6=B 不要人工确认，但风控阻断是**阻断不是确认** → 阻断后无前端弹窗提示 | WebSocket 推送告警 + 每日日报汇总 |
| L9 | `xtquant` 同机导入但不同 miniQmt 客户端类型（XtMiniQmt vs XtItClient）| 启动时探测 + 失败提示 |
| L10 | 模拟盘 + 实盘**同进程**风险：实盘崩溃可能拖垮模拟盘 | 启动顺序：先实盘健康检查再启动模拟盘；实盘异常不阻塞模拟盘 |

### 6.2 待用户确认的设计点

| # | 决策 | 默认 |
|---|------|------|
| D1 | 模拟盘与实盘**同进程 vs 分进程** | 默认同进程（FastAPI :8888单端口），但 cron 调度器可加进程级隔离 |
| D2 | 实盘止损/止盈逻辑与模拟盘**完全一致**还是**单独调严** | 默认一致（让小资金直接暴露在策略下，便于观察）|

| D5 | 模拟盘是否需要暂时停止（避免双盘同时跑大量委托）| 默认并行 |
| D6 | 是否需要"全市场异动监控"（盘中不持仓也监控）| 默认仅持仓监控 |
