## 1. 执行摘要

### 审计结论

通达信选股模块是一个**功能完整但工程化不足**的系统。核心选股逻辑可用，但在**安全性**、**翻译精度**、**架构一致性**三个维度存在系统性风险。

| 维度 | 评级 | 核心问题 |
|------|------|----------|
| 🔒 安全性 | ❌ 不合格 | `exec()` 无防护执行用户代码，AST沙箱可绕过 |
| 🎯 翻译精度 | ⚠️ 有风险 | 仅覆盖TDX 10个函数（约20%），正则翻译有误匹配风险 |
| 🏗️ 架构设计 | ⚠️ 有风险 | 职责混乱、上帝函数、硬编码遍布 |
| 🔢 信号计算 | ✅ 基本可用 | 核心逻辑正确但边界条件处理粗糙 |
| 🖥️ 用户体验 | ⚠️ 有风险 | TDX翻译前端为空壳，反馈不充分 |
| 🧪 测试覆盖 | ⚠️ 覆盖不均 | 回测/执行层/TDX桥接有测试（tests/共9文件131用例），**Screener引擎和TDX翻译器零专项测试** |

## 3. CRITICAL 级发现

### C-01: `exec()` 无沙箱执行用户提交的策略代码

**文件**: [engine.py:111](app/strategy_factory/engine.py#L111)
**风险**: 远程代码执行 (RCE)
**影响**: 攻击者可通过策略工厂提交恶意代码，读取/删除服务器任意文件、建立反弹Shell

**问题定位**:
```python
# app/strategy_factory/engine.py line 111
local_vars = {"pd": pd, "np": np}
exec(code_content, local_vars)  # 直接执行用户提交的代码！
```

**绕过AST沙箱的5+种路径**:

| # | 绕过方式 | 原理 |
|---|---------|------|
| 1 | `__builtins__.__dict__['open']('...')` | AST沙箱只检查`ast.Call`的`func.id`，但属性访问`__builtins__`不在检查范围 |
| 2 | `getattr(pd, '_np')` 链式获取 | 通过pd/np等白名单对象的属性链访问危险函数 |
| 3 | `type('X', (), {'__init__': lambda s: __import__('os').system('...')})()` | 类定义中的lambda不受AST沙箱的`ast.Call`检查 |
| 4 | `().__class__.__bases__[0].__subclasses__()` | Python对象模型遍历，获取所有已加载类的引用 |
| 5 | `np.load('s3://...')` / `pd.read_csv('/etc/passwd')` | 白名单对象本身具有文件/网络IO能力 |
| 6 | `compile('...','<>','exec')` 拼写变体 | AST沙箱禁止`compile`但允许`compile`(Unicode绕过) |

**修复方案**:

```python
# 方案1: RestrictedPython 沙箱 (推荐)
# pip install RestrictedPython
from RestrictedPython import compile_restricted, safe_globals
from RestrictedPython.Eval import default_guarded_getitem
from RestrictedPython.Guards import safe_builtins, guarded_unpack_sequence

def safe_exec_strategy(code_content: str, test_df=None):
    """使用 RestrictedPython 安全执行策略代码"""
    # 1. 编译受限代码
    byte_code = compile_restricted(code_content, filename='<strategy>', mode='exec')
    if byte_code.errors:
        return {"status": "error", "message": f"安全编译失败: {byte_code.errors}"}

    # 2. 构建受限全局变量
    restricted_globals = {
        '__builtins__': safe_builtins,
        'pd': pd,
        'np': np,
        '_getitem_': default_guarded_getitem,
        '_getiter_': guarded_unpack_sequence,
    }

    # 3. 执行
    local_vars = {}
    exec(byte_code.code, restricted_globals, local_vars)
    return local_vars


# 方案2: 子进程隔离 (更安全但更慢)
import subprocess, json, tempfile

def safe_exec_in_subprocess(code_content: str, test_df=None):
    """在独立子进程中执行策略代码，限制资源"""
    with tempfile.NamedTemporaryFile(mode='w', suffix='.py', delete=False) as f:
        f.write(code_content)
        f.write("\nimport json; print(json.dumps({'status': 'ok'}))")
        tmp = f.name
    try:
        result = subprocess.run(
            ['python', tmp],
            capture_output=True, timeout=10,  # 10秒超时
            text=True, cwd=tempfile.gettempdir()  # 限制工作目录
        )
    finally:
        os.unlink(tmp)
    return json.loads(result.stdout)
```

```python
import re

def _validate_strategy_name(name: str) -> str:
    """验证策略名称安全性：只允许字母、数字、下划线、中文"""
    if not name:
        raise ValueError("策略名称不能为空")
    # 只允许安全的文件名字符
    if not re.match(r'^[\w一-鿿]+$', name):
        raise ValueError(f"策略名称包含非法字符: {name}")
    # 解析后验证确实在策略目录内
    target = (STRATEGY_DIR / f"{name}.py").resolve()
    if not str(target).startswith(str(STRATEGY_DIR.resolve())):
        raise ValueError(f"策略名称导致路径逃逸: {name}")
    return name

def save_and_reload(self, name: str, code_content: str):
    name = _validate_strategy_name(name)  # 增加验证
    file_path = STRATEGY_DIR / f"{name}.py"
    # ... 其余逻辑不变

def delete_local_strategy(self, name: str):
```

### H-01: TDX翻译器覆盖率严重不足 (10个函数 / 约20%)

**文件**: [translator.py:91-104](app/strategy_factory/translator.py#L91-L104)
**风险**: 翻译结果不完整，用户以为翻译成功实际逻辑缺失

**覆盖率分析**（已核实 func_patterns 实际为10个映射）:

| TDX函数类别 | 总数(估) | 已覆盖 | 覆盖率 |
|-------------|---------|--------|--------|
| 数学函数 (ABS/MAX/MIN) | 10 | 3 | 30% |
| 引用函数 (REF/MA/EMA) | 8 | 3 | 38% |
| 统计函数 (HHV/LLV) | 8 | 2 | 25% |
| 逻辑函数 (CROSS/IF) | 8 | 2 | 25% |
| 查找函数 (BARSLAST/FILTER/VALUEWHEN) | 6 | 0 | 0% |
| 绘图函数 (PLOYLINE/DRAWLINE) | 5 | 0 | 0% |
| 字符串函数 (CODELIKE/NAMELIKE) | 4 | 0 | 0% |
| 高级函数 (BACKSET/ZIG) | 6 | 0 | 0% |
| **合计** | **~55** | **10** | **~20%** |

**已覆盖的10个函数**: MA, EMA, REF, LLV, HHV, ABS, MAX, MIN, CROSS, IF

**缺失的关键函数**: `BARSLAST`, `FILTER`, `PLOYLINE`, `CODELIKE`, `NAMELIKE`, `EVERY`, `EXIST`, `VALUEWHEN`, `SMA`, `WMA`, `DMA`, `BACKSET`, `ZIG`

**正则翻译的误匹配风险**:

```python

# 当用户写 C1:=... 时，C1 中的 C 会被替换

# 第2轮: MA(CROSS(c.rolling(5).mean(), c.rolling(10).mean()), 3)
# 第3轮: MA(((c.rolling(5).mean() > c.rolling(10).mean()) & (...)), 3)
# 无法继续展开外层 MA!
```

### H-03: MyTT `FILTER` 函数直接修改输入数组（副作用）

**文件**: [MyTT.py:103-105](app/indicators/MyTT.py#L103-L105)
**风险**: 数据污染，后续计算使用被修改的数据
**影响**: 在同一数据上多次调用FILTER会得到不同结果

**问题定位**:
```python
def FILTER(S, N):
    for i in range(len(S)): S[i+1:i+1+N]=0  if S[i] else S[i+1:i+1+N]
    return S  # 直接修改了输入数组S！
```

**修复方案**:
```python
def FILTER(S, N):
    """FILTER函数，S满足条件后，将其后N周期内的数据置为0 (不修改原数组)"""
    S = S.copy()  # 防止副作用
    for i in range(len(S)):
        S[i+1:i+1+N] = 0 if S[i] else S[i+1:i+1+N]
    return S
```

### H-05: `PLOYLINE` Python实现与TDX行为偏差

**文件**: [ma5_angle_tdx_v2.py:59-74](app/screener/strategies/ma5_angle_tdx_v2.py#L59-L74)
**风险**: 信号结果与TDX原始公式不一致
**影响**: 选股结果与通达信实盘结果偏差

**问题定位**:

TDX的`PLOYLINE(COND, VALUE)`是一个**绘图函数**，它将满足COND条件的K线用折线连接。在TDX选股公式中，它被用于记录金叉/死叉时的角度值，形成三角形收敛判断。

Python实现与TDX行为的差异:
1. TDX的PLOYLINE是**序列级别**的，每根K线都有值（前一次COND成立时的VALUE延续到下一次）
2. Python实现是逐code groupby后手动遍历，**排序依赖index**而非日期
3. TDX中`X3 < REF(X3,5)`的REF是5个**交易日**，Python中`shift(5)`也是5行，但如果数据有停牌缺口，行为不同

**修复方案**:
```python
def _ployline_tdx(cross_series: pd.Series, value_series: pd.Series) -> pd.Series:
    """
    严格匹配TDX的PLOYLINE行为:
    - 当cross为True时，记录当前value
    - 否则延续上一次cross时的value
    - 输出序列长度 = 输入长度
    - NaN只出现在cross从未触发前的位置
    """
    result = pd.Series(np.nan, index=cross_series.index, dtype=float)
    last_val = np.nan
    for i in range(len(cross_series)):
        if cross_series.iloc[i]:
            last_val = value_series.iloc[i]
        if not np.isnan(last_val):
            result.iloc[i] = last_val
    return result
```

```python
def extract_docstring(self, file_path: Path) -> str:
    """仅通过AST提取docstring，不执行代码"""
    import ast
    with open(file_path, "r", encoding="utf-8") as f:
        tree = ast.parse(f.read())
    for node in ast.walk(tree):
        if isinstance(node, (ast.FunctionDef, ast.ClassDef, ast.Module)):
            doc = ast.get_docstring(node)
            if doc:
                return doc.strip()
    return "No docstring found"
```

```python
    name: str
    type: type
    default: Any
    description: str = ""
    min_value: float | None = None

class BaseStrategy(ABC):
    param_schema: list[ParamDef] = []  # 子类声明参数契约
```

## 7. 维度交叉分析

### 安全 × 翻译精度 = 公式注入

用户通过TDX翻译器提交恶意公式 → 翻译器生成的Python代码包含危险调用 → `test_syntax_secure` 中 `exec()` 执行 → RCE

**攻击链**:
```
TDX公式: "X:=1; __import__('os').system('rm -rf /'); X"
→ 翻译后Python: x = 1; __import__('os').system('rm -rf /'); x
→ exec()执行 → RCE
```

### 翻译精度 × 用户体验 = 虚假信任

用户提交TDX公式 → 翻译器只覆盖15%函数 → 大量逻辑被丢弃 → 生成"看起来对但实际缺逻辑"的Python代码 → 用户以为翻译成功，实盘使用 → **选股信号与TDX不一致** → 亏损

### 架构 × 测试 = 回归风险

`run_scan` 522行上帝函数 + 零测试覆盖 = 任何修改都可能引入无法检测的回归缺陷

```python
# app/strategy_factory/security.py
"""策略代码安全模块"""

import ast
import re
from pathlib import Path

STRATEGY_DIR = Path(__file__).parent.parent / "screener" / "strategies"

# === 1. 策略名称验证 ===
def validate_strategy_name(name: str) -> str:
    if not name or len(name) > 100:
        raise ValueError("策略名称长度须在1-100之间")
    if not re.match(r'^[\w一-鿿]+$', name):
        raise ValueError(f"策略名称包含非法字符: {name}")
    target = (STRATEGY_DIR / f"{name}.py").resolve()
    if not str(target).startswith(str(STRATEGY_DIR.resolve())):
        raise ValueError(f"路径逃逸: {name}")
    return name


# === 2. AST沙箱增强 ===
FORBIDDEN_MODULES = {
    'os', 'sys', 'subprocess', 'shutil', 'socket', 'http',
    'urllib', 'requests', 'ftplib', 'smtplib', 'asyncio',
    'importlib', 'ctypes', 'multiprocessing', 'signal',
    'pathlib', 'io', 'tempfile', 'shelve', 'pickle',
    'marshal', 'codecs', 'runpy', 'pkgutil',
}

FORBIDDEN_ATTRS = {
    '__builtins__', '__class__', '__bases__', '__subclasses__',
    '__globals__', '__code__', '__closure__', '__dict__',
}

FORBIDDEN_FUNCTIONS = {
    '__import__', 'eval', 'exec', 'compile', 'open',
    'breakpoint', 'exit', 'quit', 'help', 'input',
    'memoryview', 'type', 'globals', 'locals',
}


def validate_strategy_code_v2(code: str) -> tuple[bool, str]:
    """增强版AST沙箱"""
    try:
        tree = ast.parse(code)
    except SyntaxError as e:
        return False, f"语法错误: {e}"

    for node in ast.walk(tree):
        # 检查 import
        if isinstance(node, ast.Import):
            for alias in node.names:
                root = alias.name.split('.')[0]
                if root in FORBIDDEN_MODULES:
                    return False, f"禁止导入模块: {alias.name}"

        if isinstance(node, ast.ImportFrom):
            if node.module:
                root = node.module.split('.')[0]
                if root in FORBIDDEN_MODULES:
                    return False, f"禁止从 {node.module} 导入"

        # 检查函数调用
        if isinstance(node, ast.Call):
            if isinstance(node.func, ast.Name):
                if node.func.id in FORBIDDEN_FUNCTIONS:
                    return False, f"禁止调用函数: {node.func.id}"

            # 检查属性访问
            if isinstance(node.func, ast.Attribute):
                if node.func.attr in FORBIDDEN_ATTRS:
                    return False, f"禁止访问属性: {node.func.attr}"
                if node.func.attr.startswith('__') and node.func.attr.endswith('__'):
                    return False, f"禁止访问dunder属性: {node.func.attr}"

        # 检查属性访问 (非调用)
        if isinstance(node, ast.Attribute):
            if node.attr in FORBIDDEN_ATTRS:
                return False, f"禁止访问属性: {node.attr}"
            if node.attr.startswith('__') and node.attr.endswith('__'):
                return False, f"禁止访问dunder属性: {node.attr}"

    return True, "OK"


# === 3. 安全执行器 ===
def safe_execute_strategy(code: str, test_df=None):
    """在RestrictedPython沙箱中执行策略代码"""
    try:
        from RestrictedPython import compile_restricted, safe_globals
        from RestrictedPython.Guards import safe_builtins
    except ImportError:
        raise RuntimeError("请安装 RestrictedPython: pip install RestrictedPython")

    byte_code = compile_restricted(code, filename='<strategy>', mode='exec')
    if byte_code.errors:
        return {"status": "error", "message": f"安全编译失败: {byte_code.errors}"}
    if byte_code.warnings:
        import warnings
        for w in byte_code.warnings:
            warnings.warn(f"策略代码安全警告: {w}")

    import pandas as pd
    import numpy as np

    restricted_globals = {
        '__builtins__': safe_builtins,
        'pd': pd,
        'np': np,
    }

    local_vars = {}
    exec(byte_code.code, restricted_globals, local_vars)
    return local_vars
```
