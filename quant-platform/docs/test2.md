## 0. 文档元信息

### 0.1 读者与评审

| 角色 | 关注点 | 必须评审项 |
|---|---|---|
| 用户/项目负责人 | 业务正确性、资金安全、投产路径 | 决策记录、风控闸门、实施计划 |
| 架构师 | 部署形态、模块解耦、xtquant 集成 | 总体架构、部署架构、xtquant 适配层 |
| 开发 | 代码组织、接口契约、数据模型 | 模块设计、数据模型、关键流程 |
| 运维 | NSSM、Docker、日志、监控 | 部署、可观测性、应急 |
| 测试 | 单元测试、集成测试、影子模式 | 验收清单 |

### 0.2 术语表

| 术语 | 定义 |
|---|---|
| QMT | 券商量化交易终端 |
| MiniQMT | QMT 的极简客户端 XtMiniQmt.exe |
| xtquant | QMT 官方 Python SDK |
| 实盘单 | 通过 MiniQMT 真实发到券商柜台的委托 |
| 模拟盘 | p9 既有 sim_trader |
| 回测 | p9 既有 backtest |
| 影子模式 | v4.0 预留接口，v4.0 不实现 |
| kill switch | 一键全局停机 |
| dry-run | 全流程跑通但不下真实单 |
| 熔断器 | 连续 N 次 QMT 调用失败 → 30s 拒绝 |
| 清理锁 | 按 (env, account, code) 三元组加锁 |
| 风控闸门 | 下单前 8 闸检查 |
| 回调 | QMT 异步推送的事件 |
| NSSM | Windows 服务封装工具 |
