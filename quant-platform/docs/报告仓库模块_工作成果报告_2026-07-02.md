### 3.3 P2 阶段：让仓库跑得更好

#### P2-1 ✅ 报告生成异步化

**缺陷**: H3（🟠 高）
**改动文件**: `app/api/agents.py` · `static/js/main.js`

**架构改造**:

```
改动前（同步阻塞）:
  浏览器 → POST /analyze/{code} → [等 30-60s] → 返回报告

改动后（异步轮询）:
  浏览器 → POST /analyze/{code} → 返回 task_id
  浏览器 → GET /task/{id} 每1.5秒 → 返回进度(0-100%)
  浏览器 → GET /reports/content/{id} → 返回报告
```

**后端新增**:

| 组件 | 说明 |
|------|------|
| `_report_tasks` | 内存任务管理器（Dict，线程安全） |
| `_executor` | ThreadPoolExecutor(max_workers=2) |
| `_do_generate()` | 后台线程执行报告生成 |
| `_cleanup_old_tasks()` | 清理 >30 分钟的已完成任务 |
| `GET /api/agents/task/{task_id}` | 新端点：查询任务状态/进度 |

**前端新增**:
- 轮询定时器 `_reportPollTimer`
- 进度百分比显示 `⏳ 生成中 50%...`
- 兼容旧版同步返回（graceful degradation）
- 超时保护（120 次轮询 = 3 分钟）
