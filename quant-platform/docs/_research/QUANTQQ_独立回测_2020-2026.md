# QUANTQQ 策略独立回测报告(2020.1.1 → 2026.7.13)

> **目的**:在不依赖系统数据层/接口/调度的前提下,验证 QUANTQQ 选股策略本身能否跑出正期望。
> **数据**:TDX 公式信号 + 系统 parquet OHLCV(2015-2026),无 akshare/yfinance 网络依赖。
> **退出规则**:9 条,内嵌自 `app/backtest/exit_rules.py`,优先 `trailing_first` 模式。
> **摩擦**:佣金 0.025%/双边 + 滑点 0.05%/side + 印花税 0.1%(仅卖出)。
> 单笔上限 `$200k` 或 `$500k`(按配置),仓位数不限(除 v3)。
> **资金**:CNY 1,000,000 起步。

## 〇、所有回测参数完整清单(底层数据,直接读自 `config/app_setting.json`)

### A. 风控与退出参数(`risk` 段,百分比命名 / `backtest` 段,小数命名,二源已对齐校验)

| 参数 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `hard_stop` | 浮点(小数) | **-0.046** | 硬止损线。`entry_price * (1 + hard_stop) = 9.54`。跌破即卖出(已用日 **Low** 检测兜底 close) |
| `take_profit_tiers` | list | `[{profit_pct: 0.027, sell_ratio: 0.20}, {profit_pct: 0.13, sell_ratio: 0.60}]` | 多档止盈(同 bar 叠加模式 VERA 对齐)。TP1 +2.7%:卖 20%(成交价 `entry_price × 1.03`);TP2 +13.0%:卖剩余的 60% |
| `trail_activate` | 浮点(小数) | **0.039** | 移动止盈激活阈值。峰值盈利 ≥ +3.9% 才开始回撤监测 |
| `trail_dd` | 浮点(小数) | **0.017** | 移动止盈回撤距离。峰值 → 跌 ≥ 1.7% 即卖出(成交价 = 峰值 × 0.983) |
| `breakeven_threshold_pct` → `breakeven_threshold` | 百分比 / 小数 | 2.23% / **0.0223** | 保本止损激活阈值。峰值盈利 ≥ +2.23% 后自动激活下一条 |
| `breakeven_stop_pnl_pct` → `breakeven_stop` | 百分比 / 小数 | 0.98% / **0.0098** | 保本止损位。激活后,止损位移到 `entry_price * 1.0098`(+0.98% 锁利) |
| `time_exit_days` | 整数 | **7** | 时间条件退出天数(超 7 天) |
| `time_exit_profit` | 浮点(小数) | **0.025** | 时间退出盈利阈值(收盘 > +2.5%) |
| `time_exit_force_days` | 整数 | **12** | 强制时间退出天数(无条件清仓) |
| `first_day_exit_min_profit` | 浮点(小数) | 0.0(**禁用**) | 首日弱势离场阈值。0 = 永远不触发 |
| `first_day_exit_days` | 整数 | 1 | 首日弱势离场窗口 |
| `use_atr_trail` | bool | False(**禁用**) | ATR 动态止盈。本回测未启用 |
| `atr_trail_multiplier` | 浮点 | 2.5 | ATR 倍数(若启用) |

### B. 退出规则框架

| 参数 | 默认值 | 含义 |
|---|---|---|
| `priority_mode` | **`trailing_first`** | 优先级模式:TP > 移动止盈 > 硬止损 > 保本 > 首日 > 强制时间 > 时间(VERA 对齐)。盘中触及止损线但同日也触及止盈目标时,止盈先触发卖部分,不全仓止损出局 |
| `tp_stack_mode` | **True** | 阶梯止盈叠加模式。同 bar 内所有未触发档位全触发,按最高档成交价,`sell_ratio` 累加钳位 1.0 |
| `tp1_fill_pct` | **0.03** | TP1 实际成交价固定比例。VERA 对齐(entry × 1.03),不复用 TP1 目标价的 +2.7% |
| `realistic_stop_fill` | "stop" | 止损成交价假设。`"stop"`=纯止损线对齐 VERA,`"min"`=min(stop, open) 真实跳空开盘,`"max"`=max(stop, open) 旧乐观 |
| `first_day_hold_value` | 2 | `simple_runner / sim_trader` 的首日 hold_days 值(含首日之计);`5m / 日线回退`引擎用 1 |

### C. 退出规则(9 条,按 `trailing_first` 优先级)

| 优先级 | 规则名 | 触发条件 | 决策 |
|---|---|---|---|
| 110 | `rule_take_profit` | `close >= entry_price * (1 + tp_pct)`(触发档位)`hold_days >= 2` | 卖出档位对应 `sell_ratio` 部分(同 bar 多档可叠加) |
| 105 | `rule_trailing_stop` | `peak_pct >= trail_activate (=3.9%)` **AND** `low / peak_price - 1 <= -trail_dd (=-1.7%)` | 卖出剩余全部(剩余 ≥ 0) |
| 100 | `rule_hard_stop` | `hold_days >= 2` **AND** `(low <= stop_price)` 或 `(close/entry - 1 <= hard_stop)` | 卖出剩余全部 |
| 95 | `rule_breakeven_stop` | `hold_days >= 2` **AND** `peak_pct >= breakeven_threshold (=2.23%)` **AND** `low / close <= entry_price * (1 + breakeven_stop)` | 卖出剩余全部(止损位 +0.98% 锁利) |
| 90 | `rule_first_day_exit` | `first_day_exit_min_profit > 0` **AND** `hold_days ∈ [2, 2+days-1]` **AND** `high/entry - 1 < fd_min_profit` | 卖出剩余全部。本回测 fd_min_profit = 0,**永不触发** |
| 80 | `rule_time_force` | `hold_days > time_force_days (=12)` | 卖出全部(强制清仓,任何盈亏) |
| 20 | `rule_time_condition` | `hold_days > time_exit_days (=7)` **AND** `close/entry - 1 > time_exit_profit (=2.5%)` | 卖出全部(赚钱了才出) |

> `rule_vol_climax_exit`(成交量高潮离场)— 系统里有,但本回测未实现(vol_climax_enabled 默认为 False,无 20 日均量计算)。若启用需额外给 RuleContext 注入 `vol_climax_avg / vol_climax_day_vol / high / low / close`。

## 三、关键发现

### 1. 信号密度是真正瓶颈(非资金)

| | 单笔 20万 | 单笔 50万 |
|---|---|---|
| **前 300** | v4: +526% | v5b: +1231% |
| **全 A**   | v5a: +10508% | v5c: +25214% |

**横向**比较:池子变大 → 单笔金额不变的情况下,笔数 16× 增长 → 总收益 16-20× 提升。
**纵向**比较:单笔金额变大 → 每笔金额变大,但单笔胜率略降(-0.4pp) → 收益仅 +2.4×。

→ **池子大小 比 单笔金额重要**(都是放大收益,但池子放大效果更线性)。

### 2. 笔均收益"几乎不变"

v3 ~ v5c 的笔均都在 **+5.3% 到 +6.2%** 之间。池子和单笔金额只影响"开多少笔",不影响"每笔赚多少"。这说明:
- 策略的 edge per trade 不依赖规模
- 在(至少)单笔 50 万以内,没有策略容量衰减
- 若规模再大(100 万 / 笔),**可能**开始出现 edge 衰减(待验证)

### 3. 最大回撤与单笔金额正相关

| 配置 | 最大回撤 |
|---|---|
| 20 万 + 5 仓 | -7.69% |
| 20 万 + 不限仓 | -7.61% |
| 50 万 + 前 300 | **-15.55%**(↑ 翻倍) |
| 全 A + 20 万 | -13.23% |
| 全 A + 50 万 | -12.63%(分散抵消) |

→ **单笔金额越大 → 单仓错杀的影响越大 → 回撤加深**。但**池子扩大会稀释集中度**(v5c -12.6% < v5b -15.5%)。

### 4. 退出规则分布稳定

5 个版本的"退出规则触发频率"几乎一致:
- **TR(移动止盈)** ~50% 笔数
- **HS(硬止损)** ~24%
- **TP1 + TP2(双档止盈)** ~16%
- **BE(保本锁利)** ~7%

策略的核心驱动 = 移动止盈 + 保本锁利的组合。**这两条是否启用,直接决定胜负**(v1 没启用 BE → 亏)。

## 四、现实性修正

| 摩擦项 | 当前模型 | 现实估计 | 影响 |
|---|---|---|---|
| 滑点 | 0.05%/side | 0.1-0.3%/side | CAGR -2 ~ -5pp |
| 印花税 | 0.1% | 0.1% | 已含 |
| 价差 | 0 | 0.02-0.05% | CAGR -1pp |
| 隔夜跳空 | 0(均按 close) | 实际开盘常有 0.5-1% 跳空 | CAGR -3 ~ -7pp |
| 流动性 | 0 | 大仓单对中盘股有 0.2-0.5% 冲击 | CAGR -5 ~ -15pp(规模大时显著) |
| 网络/停机风险 | 0 | 1-3 起/年,平均 -1% | CAGR -1 ~ -3pp |

**建议把上面的 +50% 视为风险缓冲**。如果你用 100 万本金,真实的 CAGR 估算:
- **保守**:v5a 115% - 50pp = **~65%**
- **乐观**:v5a 115% - 20pp = **~95%**
- **对比沪深 300 指数同期约 +5%/年**,策略仍 10-20× 跑赢
