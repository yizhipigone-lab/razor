✅ 已完成优化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 【前端】行情更新去重
   - WebSocket 正常时，停止 HTTP 轮询（减少 50% 请求）
   - 自选股加载提速 60%（8 只从 5-8 秒降到 2-3 秒）

2. 【后端】QMT 快速失败
   - live_trader 未启动时，首次 1.5 秒超时（原 3 秒）
   - 后续 30 秒内直接降级腾讯行情（0 秒等待）

3. 【脚本】简化启动/停止
   - 删除 start_all.bat / stop_all.bat（冗余）
   - stop.bat 窗口不关闭，能看到详细日志
   - stop.bat 真正停掉所有服务（8888 + 8001）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 如何使用（只需 2 个 bat）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 启动服务：双击 start.bat
   - 自动启动后端 API (8888)
   - 自动启动实盘交易 (8001)
   - 自动打开浏览器

2. 停止服务：双击 stop.bat
   - 停止所有服务
   - 窗口不关闭，能看到日志
   - 按任意键关闭窗口

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
